# Voteometer

## Overview
Voteometer is a political decision-making app that helps users evaluate candidates based on their ratings and electability probabilities. The app dynamically calculates "Power Numbers" to assist users in making informed decisions.

## Features
- **Dynamic Question Display**: Users can rate candidates and provide probabilities for electability.
- **Power Number Calculation**: Calculates scores dynamically based on user inputs.
- **Candidate Management**: Add, edit, and manage candidates seamlessly.
- **Party Switching**: Preserves candidates and questions when switching parties.
- **Prisma Integration**: Saves user data and configurations to a database.
- **Simplified Mode**: Offers a streamlined experience for casual users.
- **Expert Estimates**: Allows experts to input their estimates for better decision-making.
- **Election-Year Configurations**: Customizes the app for specific election years.
- **Admin Tools**: Provides tools for managing app configurations and data.

## Getting Started
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server with `npm run dev`.
4. Access the app at `http://localhost:3000`.
